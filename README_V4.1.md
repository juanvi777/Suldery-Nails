# SULDERY NAILS v4.1

Cambios:
- Botón y panel independiente para Fotos de clientas.
- Fotos de inicio separadas de las fotos que ven las clientas.
- Nail Lab con asistente conversacional local basado en la base de conocimiento del proyecto, generador de diseños, aprendizaje y cuidados.
- Identidad visual rosada; modo oscuro negro con haces de luz rosados.
- Marcos flotantes para fotografías.
- Caché versionada v4.1.

La función de asistente no requiere una API de pago; utiliza el conocimiento integrado del proyecto y reglas deterministas.
