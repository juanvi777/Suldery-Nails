SULDERY NAILS v4.4

Cambios:
- Flujo de reserva por pasos: servicio → día → hora → confirmación.
- Panel de estado del día con cada media hora marcada como disponible, ocupada, almuerzo, bloqueada, pasada o no disponible.
- Creación de cita idempotente para evitar falsos “espacio ocupado” al repetir una solicitud.
- Tras guardar una cita, un fallo de refresco de agenda no reemplaza el mensaje de éxito.
- Catálogo con precarga de fotos cercanas para que navegar sea más fluido incluso con catálogos grandes, sin descargar cientos de imágenes de una vez.
- Restricción CORS más estrecha para el proyecto de GitHub Pages.
