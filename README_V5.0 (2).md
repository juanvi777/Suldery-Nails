# SULDERY NAILS v5.0

## Objetivo
Versión orientada a producción con reservas robustas y avisos web gratuitos.

## Avisos
- Se comprueba la salud real de las suscripciones de cada dispositivo.
- Las suscripciones obsoletas o rechazadas por el servicio push se eliminan.
- Si el permiso del navegador sigue concedido y la suscripción desaparece, la aplicación intenta recuperarla al volver a abrirse.
- La dueña puede ver si cada clienta tiene avisos activos, necesita una prueba o requiere revisión.
- Recordatorios automáticos: 30 minutos y 10 minutos antes de cada cita confirmada, para clienta y dueña.
- Los cambios de cuenta y de cita generan avisos a las personas correspondientes.

## Fotos

Las seis tarjetas de resumen se muestran en una cuadrícula 3x2 en escritorio: clientas activas, citas agendadas, calendario, recuperar acceso, calificaciones y notificar.
