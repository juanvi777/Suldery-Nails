# Suldery Nails v5.7

## Cambios

- El visor del tutorial muestra directamente el PDF seleccionado dentro del cuadro del tutorial, con fallback para abrir el PDF completo si el navegador no puede incrustarlo.
- Se mantienen los dos PDFs: Android e iPhone/iOS.
- La disponibilidad de citas exige que el servicio completo tenga un hueco libre antes de la siguiente cita. Un hueco de 30 minutos nunca se muestra para un servicio de 60 minutos.
- La validación se mantiene tanto al mostrar horarios como al confirmar la cita en el backend.
- Al final del horario normal se permite seleccionar el inicio aunque la duración termine después del cierre; la solicitud queda para decisión de Suldery.
