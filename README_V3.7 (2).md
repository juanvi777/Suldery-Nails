# Suldery Nails v3.7

Cambios principales:
- Instalación PWA guiada en iPhone/iPad: en iOS la web debe agregarse a la pantalla de inicio y luego permitir notificaciones.
- Service Worker y cache busting actualizados.
- Apple Touch Icon presente en las páginas.
- Nail Lab IA gratuito: creador de propuestas de diseño, base de conocimiento y catálogo de inspiración.
- Guía de cuidado integrada dentro de Nail Lab.
- Recuperación gratuita por número de teléfono mediante solicitud a Suldery; no depende del correo.

Nota: el Nail Lab es un asistente local basado en una base curada y reglas de combinación. No es una IA general ni garantiza respuestas 100% racionales; no usa una API de pago.
