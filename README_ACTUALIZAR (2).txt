SULDERY NAILS — actualizar

1. Extrae esta versión sobre C:\proyectos\Suldery nails sin borrar .git.
2. En PowerShell: git add -A
3. git commit -m "Suldery Nails v3.5 - avisos gratis y fotos"
4. git push origin main
5. Para desplegar directamente en Railway: railway up

Avisos gratis:
- No necesita Telegram ni Twilio.
- La dueña entra al panel y pulsa “Activar avisos”.
- La clienta puede activar sus avisos tras registrarse o desde su panel.
- Los avisos se entregan mediante Web Push del navegador.

Fotos:
- Máximo 8.
- Una foto solo puede quedar en inicio de sesión o página de clienta.
- Cada foto aparece una por una y se puede cambiar o eliminar.
